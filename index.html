What it does today

A small, usable loop for prompt testing

01

Save cases as JSON

Keep system prompts, representative inputs, and expectations reviewable in version control.

02

Assert on outputs

Check for required or forbidden phrases and response-length boundaries.

03

Dry-run for free

Validate suite structure and checks using fixture responses with zero model requests.

04

Run against Claude

Optionally send cases to Anthropic's API using your own key; live usage may cost money.

Quickstart

Try the test runner without signing up or spending credits.

Install Node.js 20+, clone the repository, and run the included tests and sample suite:

$ npm test
$ npm start -- run --file examples/sentiment.json --dry-run
No API key · no network · no charges

For live tests, create your own Anthropic Console API key, keep it in an ignored `.env` file, and choose an API model available to your account. API usage can incur charges.

Why this exists

Prompt changes deserve repeatable checks.

A prompt that worked on one example can fail on a different kind of input. Saving representative cases makes expected behavior explicit and lets developers re-check it after edits.

This first version is deliberately modest: text assertions are not a substitute for expert review, and model outputs can vary. It gives developers a repeatable starting point, not a quality or safety guarantee.
